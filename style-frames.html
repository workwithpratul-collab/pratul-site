The Ascent · style frames

Live renders from the real engine and the shared palette. Base camp and the ridge are the finished Phase 1 film; the meadow and the summit are first style frames.

How to read this sheet

One world, four lights. The same painted shaders, fog and mist run in every frame; only the palette preset changes (see the style guide).

For a clean 1920 × 1080 screenshot, open a frame at full size in a 1920 × 1080 window. Frames pause a few seconds after loading to save your graphics card.
